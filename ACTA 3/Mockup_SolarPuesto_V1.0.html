🔥 Dimensionamiento del sistema solar

Ejemplos por tipo de puesto, con los componentes que necesitas y cómo instalarlos y usarlos de forma segura.

1. Puesto de jugos 🥤

LicuadoraCuchillosNevera portátil*
Panel 450WBatería 12VInversor 1200W
  1. Coloca la licuadora solo con el inversor encendido.
  2. Usa la licuadora a ráfagas (no continua) para ahorrar batería.
  3. Carga el teléfono / datáfono en las horas sin uso.
  4. Al cerrar, apaga el inversor y protege el panel.
⚠ Si usa nevera, no conectes licuadora y nevera al mismo tiempo.

2. Iluminación LED + celular/datáfono 📱

Lámparas LEDCelularDatáfono
Panel 100–200WBatería 12VInversor 300–600W
  1. Instala las lámparas LED sobre las áreas de atención.
  2. Elige bombillos LED de bajo consumo (5–10 W).
  3. Carga el datáfono durante el día con el panel.
  4. Apaga luces de zonas sin ventas.

3. Alimentos con refrigerador pequeño ❄️

RefrigeradorIluminación LED
Panel 500W+Batería 200AhInversor 1500W
  1. No abrir el refrigerador con frecuencia.
  2. Regula el termostato a un valor medio.
  3. Ubica el refrigerador en sombra.
⚠ Alerta: el refrigerador es el mayor consumidor. Es importante dimensionarlo junto a los demás aparatos.

4. Puesto mixto (licuadora + luces + datáfono) 🥤💡

LicuadoraLámparas LEDDatáfono
Panel 450WBatería 150AhInversor 1200W
  1. Usa la licuadora por turnos cortos.
  2. Mantén el datáfono conectado solo para cobrar.
  3. Cerciúrate de que las luces sean LED.
⚠ No exceder la capacidad del inversor combinando más de un equipo de alto consumo.

5. Puesto de fritura (elemento de calor + ventilador) 🍟

FritadoraVentiladorIluminación
Panel 600W+Batería 200AhInversor 2000W
  1. Ubica el panel y equipos lejos de aceite y agua.
  2. Habilita el ventilador para extraer humo.
  3. Revisa que los cables estén lejos de calor.
⚠ Alto consumo de calor: evaluación con experto para el dimensionamiento.
